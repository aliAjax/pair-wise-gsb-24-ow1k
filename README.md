# hxwl-10 考古探方记录 · 测年台账

遗址探方、地层关系与出土物坐标档案；当前模块为**可恢复的碳十四测年台账**。

## 技术栈

React + Vite + TypeScript + CSS（数据持久化于浏览器 localStorage，无后端）

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5110
npm run verify     # 18 项领域规则断言
npm run typecheck  # 类型检查
npm run build
```

## 台账规则

- **样本唯一绑定**：样本按「探方 + 地层 + 袋号」唯一，重复三要素无法再次登记。
- **实验室回执**：回执带报告号与校准曲线版本（IntCal13/20/25）；报告号全局唯一，
  重复报告只入一次、不重复挂到同一袋样本；回执所指三要素对不上样本时进入「待核」，
  保留原始所指信息，核对成功后再挂样本并生成校准区间；可退回实验室（区间一并停用）。
- **曲线换版**：切换当前曲线版本后，所有未批复区间立即失效并按新版重算（记录重算次数）；
  已批复结论冻结当时的区间与曲线版本，不再随换版改动。
- **发布把关**：同探方内地层号小者在上（更晚、cal BP 更小）。若新结果造成上下年代倒置，
  「发布年代报告」按钮被挡下，并列出矛盾的探方、地层与样本（上/下层区间）；
  矛盾解除（退回回执/重新核对/以批复保留）后方可发布。
- **失败可恢复的批次导入**：批次以完整记录保存并逐条处理，可模拟处理到第 N 条中断；
  中断或刷新页面后批次标记为「待恢复」，恢复时只补未完成条目，
  已存在的样本跳过、已入账回执不重复挂。
- **页面重开继续整理**：全部台账状态实时落盘，重新打开页面自动接续。

## 代码结构

- `src/types.ts`：台账领域类型
- `src/domain.ts`：校准、地层上下序校验、发布结论等纯逻辑
- `src/store.tsx`：reducer、回执入账/待核、换版重算、批次恢复、localStorage 持久化
- `src/App.tsx`：台账界面（样本、回执、年代区间、发布把关、批次导入、操作日志）
- `scripts/verify.ts`：领域规则断言脚本
