# hxwl-10 考古探方记录 · 测年台账

遗址探方、地层关系与出土物坐标档案，含可恢复的测年台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 测年台账功能

- **样本唯一绑定**：样本按 探方 + 地层 + 袋号 唯一登记，同一袋样本不重复入账
- **实验室回执**：回执带报告号与校准曲线版本；重复报告只入一次；对不上样本的回执先留待核，可挂接或作废
- **曲线版本更新**：升级校准曲线后，未批复的年代区间立即失效并按新曲线重算（旧区间留痕）；已批复结论保留批复时的曲线版本与区间
- **层序校验**：新结果若使上层样本最早边界老于下层样本最晚边界，判定层序矛盾，挡住该探方报告发布并列出探方、地层与样本
- **可恢复导入**：批次逐条落盘，导入失败或关页后从完整批次恢复、只补未完成样本；重放同一批次不重复挂回执；台账存于 localStorage，页面重新打开可继续整理

## 目录

- `src/ledger/types.ts` 领域模型（样本 / 回执 / 结论 / 批次 / 发布）
- `src/ledger/curves.ts` 校准曲线与区间换算（内置简化模型）
- `src/ledger/stratigraphy.ts` 层序矛盾检查与探方-地层汇总
- `src/ledger/store.ts` 台账状态、幂等回执入账、localStorage 持久化
- `src/App.tsx` 台账界面

可继续扩展 IndexedDB、权限、后端 API 和复杂图表。
